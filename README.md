# RABI3 PS3 Gaming Library

موقع مكتبة ألعاب PS3 لشركة الربيع، باللغة العربية، جاهز للنشر على GitHub Pages.

## محتويات المشروع
- `index.html` صفحة الموقع الرئيسية.
- `style.css` تصميم متجاوب بهوية الربيع الكحلي والبرتقالي.
- `app.js` البحث والفلترة والتصنيف والترتيب ونافذة تفاصيل اللعبة.
- `games.json` بيانات المكتبة.
- `assets/rabi3-logo.jpg` اللوجو الأصلي المرسل من المستخدم.

## عدد الألعاب
- 200 عنوانًا مأخوذًا من ملف الحصر.
- PES 2026 (Community Patch) مدرجة كإضافة منفصلة بطلب المستخدم، وليست ضمن ألعاب الفيديو.
- العدد الإجمالي المعروض بالموقع: 201.

## نشر الموقع على GitHub Pages
1. فك ضغط ملف المشروع.
2. أنشئ Repository جديدًا على GitHub.
3. ارفع **كل محتويات المجلد** إلى جذر المستودع، بحيث يكون `index.html` في الجذر مباشرة.
4. افتح `Settings` ثم `Pages`.
5. من `Build and deployment` اختر `Deploy from a branch`.
6. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط `Save`.
7. انتظر قليلًا حتى يظهر رابط الموقع في صفحة Pages.

## الصور
الموقع يحاول جلب صور توضيحية للألعاب تدريجيًا من Wikipedia API. بعض الألعاب قد لا يكون لها صورة مناسبة أو قد لا تكون الصورة هي غلاف PS3 الأصلي؛ في هذه الحالة تظهر بطاقة مصممة باسم اللعبة بدلًا من صورة غير مؤكدة.

## ملاحظات
- أسماء الفروع مدرجة دون عناوين تفصيلية أو أرقام هواتف حتى لا نضيف بيانات غير مؤكدة.
- PES 2026 على PS3 تعامل كباتش مجتمعي غير رسمي، وليست لعبة PS3 رسمية مستقلة.
